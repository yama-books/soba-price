## データの流れ
- 出典候補: sources/catalog.csv
- 原史料未照合の調査候補: sources/price_leads.csv（本番データにしない）
- 利用許諾と照合が取れた観測値: data/verified/（現在0件）
- 計算根拠付きの生成結果: data/derived/（現在0件）
- 年代・通貨・貨幣換算と現代購買力は、別計算方式と別ラベルで表現する。

## 実装の選択
- HTML/CSS/JavaScript の単一HTMLでまず試作し、必要になったらコンポーネント化。
- CSS transition と少量の vanilla JS を採用し、外部の大きいモーションライブラリは現段階では不要。
- GitHubにコミットしても Web公開・CI・実機操作が完了したことにはならない。
- 原史料の本文・画像・データベース大量抽出を公開Repoに直接置かない。

## リスク・禁止
- 平安期の石・反・文等を現代単位へ根拠なしで換算しない。
- 税・公定評価額・貢納・売買を同じ小売相場として平均しない。
- 年代の欠測を補間して確定価格に見せない。
- 未検証リードを精密な円換算として数値アニメーションさせない。

## 次の判断
モーションを先に大量実装せずM1試作に10件程度を絞る。試作の操作感を評価後、D0/D1の史料確保とデータスキーマへ戻り、権利・品質を確認したデータのみ本番表示する。
