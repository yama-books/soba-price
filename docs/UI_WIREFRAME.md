## 必須ビュー

1. **探索・年表**: 年代、国・都市、品目、史料区分で絞り込み。史料がない年は欠測として扱う。
2. **比較**: 複数記録を並べる。「原価格」「同時代の為替」「現代購買力」は別欄。相互比較できないものは明示。
3. **出典**: どの資料の何頁・どのデータコードか、転記者が何を検証したかを示す。
4. **詳細**: 原史料の文字、原単位、日付体系、地域、売買・税・評価額など取引種別を保持。

## モバイル・アクセシビリティ
- 検索条件は開閉式、比較リストは下部の折りたたみトレイ。
- 44px以上のタッチ領域、キーボードのフォーカス表示、Escで詳細を閉じて選択カードへ復帰。
- フィルタ切替は「わずかな動き」で即応。動きを減らすOS設定に対応。
- 研究リードと公開確認済み史料を視覚的・意味的に分離する。
