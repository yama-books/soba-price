# Data policy / データ管理方針

状態：初期方針（2026-10-17）。個別出典の二次利用可否は未判定。

## 区分
- `docs/`, `sources/catalog.csv`: 独自作成した計画・書誌メタデータ。原資料の著作物を転載しない。
- `data/verified/`: 原資料照合済みかつ公開・再配布可否を確認した加工データのみ。
- `data/derived/`: 使用した入力ID・計算式・基準年・換算方式を記録した再計算可能な結果のみ。
- `raw/`, `staging/`: 収集した原ファイルや未検証転記。原則Public Gitに置かない。必要なら利用条件を確認した別の非公開作業領域で管理。

## 登録条件
1. 出典のURLと識別子、書誌、取得日、数量・単位・年代・地域・取引種別を記録する。
2. 史料にある価格、現代換算、研究者による再構成、独自推定を別々の項目に保存する。
3. 著作権・契約・サイトの取得規約、再配布条件を出典ごとに確認する。Privateなら無条件で複製可能になるわけではない。
4. 歴博DB、CiNii論文、図書館複写物、書籍本文、PDF、画像、データベースの大量抽出を、許可なしにPublicへ置かない。
5. 史料としての正確性（S1-S4）と比較妥当性（C1-C4）は別評価。欠測を0円や架空の内挿値で埋めない。
6. 当時の為替による円換算、CPI調整、米・賃金による参考換算、銀重量を区別し、算出できない場合は「換算不可」と表示する。
7. 明示的なコード・文書ライセンスは今後検討。公開リポジトリであることだけでは再利用許諾にはならない。

## 作業ルート
資料発見 → `sources/catalog.csv` → 利用条件と閲覧方法確認 → 記録抽出 → 原史料照合 → 公開審査 → `data/verified/` → 計算とテスト → `data/derived/` → アプリ表示。
